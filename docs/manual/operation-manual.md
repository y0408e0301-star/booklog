## 1. はじめに

BookLog は、読んだ本のレビューを書き、フォローした人のレビューを読むアプリです。本棚で「読みたい」「読書中」「読了」の本を管理できます。

- 本の情報は Google Books から取ります。**Google Books で見つからない本は登録できません。** 書名などを手で入れる方法はありません（3.3）
- レビュー・写真・コメント・フォロー・本棚は、ログインしている人なら誰でも見られます。見せる人を選ぶ機能はありません
- 通知・ダイレクトメッセージ・レビューやユーザーの検索はありません。検索できるのは本だけです

### 1.1 使える環境

| 機器 | ブラウザ |
| --- | --- |
| パソコン（Windows 11） | Google Chrome、Microsoft Edge、Mozilla Firefox |
| パソコン（macOS 14 以降） | Safari、Google Chrome |
| iPhone（iOS 17 以降） | Safari |
| Android 14 以降 | Google Chrome |

- どれも最新版を使ってください。アプリのインストールは要りません。ブラウザで URL を開きます
- インターネットへの接続が必要です。つながっていないときは、画面の上に「インターネットに接続されていません。接続を確認してください。」と出ます。つながると消えます
- 費用を抑えるため、使わない間はサーバーを止めています。止めている間に開くと「BookLog は止めています」と出ます。動かしている時間に開き直してください

### 1.2 画面の見方

ログインした後の画面は、どれも一番上にヘッダーがあります。

```
┌──────────────────────────────────────────────────────────┐
│ BookLog   [ ISBN・書名で本を探す   ] 🔍     (た) ログアウト │
└──────────────────────────────────────────────────────────┘
```

| 部分 | できること |
| --- | --- |
| BookLog | 押すとタイムラインに戻る |
| ISBN・書名で本を探す | 本を探す（3 章） |
| (た)（自分の表示名の 1 文字目） | 押すと自分のプロフィールを開く |
| ログアウト | ログアウトする（2.3） |

スマートフォンなど画面の幅が狭いときは、アプリ名が「BL」になり、検索欄は 🔍 のボタンだけになります。🔍 を押すと検索欄が開きます。

## 2. アカウント

### 2.1 アカウントを作る

1. URL を開き、ログイン画面の「アカウントを作る」を押す
2. 次の 4 つを入れて「登録する」を押す

| 項目 | 決まり |
| --- | --- |
| ユーザー ID | 3〜15 文字の半角英数字と「_」。ほかの人と同じ ID は使えません（大文字と小文字の違いだけでも同じ ID とみなします）。後から変えられません |
| 表示名 | 1〜30 文字。画面に名前として出ます。後から変えられます |
| パスワード | 英字と数字を両方含む 8〜64 文字の半角文字。記号・空白も使えます |
| パスワード（確認） | パスワードと同じものをもう一度 |

- 条件に合わない項目があると、その入力欄の下に理由が出ます
- 登録するとそのままログインし、タイムラインが開きます
- メールアドレスは登録しません。**パスワードを忘れたときに再発行する方法はありません。** 忘れたときは、新しいアカウントを作ってください

### 2.2 ログインする

1. ログイン画面でユーザー ID とパスワードを入れて「ログイン」を押す
2. ログインする前に開こうとしていた画面があれば、その画面が開きます。なければタイムラインが開きます

- 一度ログインすると、**最後に使ってから 14 日間は、ブラウザを閉じてもログインしたまま**です。14 日間使わなかったときは、ログインし直してください
- ユーザー ID は大文字と小文字を区別しません
- **パスワードを 5 回続けて間違えると、そのユーザー ID では 15 分間ログインできません。** 15 分たってから、正しいパスワードでログインしてください

### 2.3 ログアウトする

ヘッダーの「ログアウト」を押します。確認なしでログアウトし、ログイン画面に戻ります。共用のパソコンでは、使い終わったら必ずログアウトしてください。

### 2.4 退会する

1. 自分のプロフィールで「プロフィールを編集」を押す
2. 画面のいちばん下の「退会する」を押す
3. 確認の画面でパスワードを入れて「退会する」を押す（「キャンセル」で何もせずに戻ります）

- **退会すると、あなたのレビュー・写真・コメント・参考になった・フォロー・本棚がすべて消え、元に戻せません。** ほかの人のレビューに付けたコメントも消えます
- 本の情報は消えません。ほかの人のレビューも残ります
- ほかのブラウザでのログインも切れます
- 退会した後は、同じユーザー ID をほかの人が登録できるようになります

## 3. 本を探す

### 3.1 探し方

1. ヘッダーの検索欄に ISBN か、書名・著者名を入れる（100 文字まで）
2. Enter キーか 🔍 を押す
3. 結果の本を押すと、その本のページが開く

- ISBN は 10 桁か 13 桁です。「-」や空白は入っていても同じです（例：978-4-10-101001-4）
- ほかの人がすでに開いた本は、同じ本のページになります
- 同じ文字で 24 時間以内に探したときは、前の結果を出します。新しく Google Books に載った本がすぐに出ないことがあります

### 3.2 結果の見方

- 1 冊ごとに、表紙・書名・著者・出版社・出版日が出ます。表紙がない本には「表紙なし」と出ます
- 20 件ずつ出ます。一番下の「もっと見る」で次の 20 件が出ます。出せるのは 100 件までなので、多すぎるときは言葉を足して絞ってください

### 3.3 見つからないとき

- 「「（入れた文字）」に一致する本は見つかりませんでした。」と出たら、別の書き方（書名の一部・著者名・ISBN）で探してください
- **それでも見つからない本は、BookLog に登録できません。** 日本の本の一部は Google Books にないか、情報が欠けています
- 「本の検索がいまできません。時間をおいてもう一度お試しください。」と出たときは、Google Books につながらないか、1 日に使える回数を超えています。回数は日本時間の 0 時に戻ります。このときも、一度開かれた本のページ・レビュー・本棚は使えます

## 4. 本のページ

本のページには、表紙・書名・著者・出版社・出版日・ISBN・紹介文、平均評価とレビューの件数、読書ステータスのボタン、その本のレビューが出ます。

- 情報がない項目は出ません。本の情報は Google Books のものをそのまま出していて、直すことはできません
- 紹介文が長いときは 5 行まで出ます。「続きを読む」で全部出ます
- レビューがまだない本は、平均評価が「—」になります
- レビューは新しい順に 20 件ずつ出ます。一番下までスクロールすると続きが出ます

### 4.1 本棚に入れる（読書ステータス）

本のページの「読みたい」「読書中」「読了」のボタンを押すと、その本を本棚に入れます。

- 別のボタンを押すと、ステータスが変わります
- 選んでいるボタンをもう一度押すと、本棚から外れます（確認は出ません）。その本に書いたレビューは消えません
- レビューを投稿すると、本棚にない本は「読了」で入ります。すでに本棚にある本のステータスは変わりません

## 5. レビュー

### 5.1 書く

1. 本のページの「レビューを書く」を押す
2. 次を入れて「投稿する」を押す（パソコンでは、感想の欄で Ctrl＋Enter、Mac では ⌘＋Enter でも投稿できます）

| 項目 | 決まり |
| --- | --- |
| 星 | 1〜5 から選ぶ（必須） |
| 感想 | 2,000 文字まで（必須）。改行できます。残りの文字数が下に出て、超えると赤い文字でマイナスになり、投稿できません |
| ネタバレあり | 結末や大事な展開に触れているときに印を付けます（5.5） |
| 写真 | 4 枚まで（5.2） |

- 1 つの本に書けるレビューは 1 人 1 つです。すでに書いた本では、ボタンが「レビューを編集」になります
- レビューは、ログインしている人なら誰でも見られます。見せたくないことは書かないでください

### 5.2 写真を添える

レビューの画面の「写真を選ぶ」を押して選びます。JPEG・PNG・WebP で、1 枚 5MB まで、1 つのレビューに 4 枚までです。

- 選んだ写真は小さく並び、それぞれの「×」で外せます
- 5 枚以上選ぶと、先に選んだものから 4 枚までを添えて「写真は 1 つのレビューに 4 枚までです。」と出ます
- 添えられない写真（5MB を超える・形式が違う）を選ぶと、その写真は添えずにメッセージが出ます

> **写真の位置情報に注意してください。** スマートフォンで撮った写真には、撮った場所の情報（位置情報）が入っていることがあります。**BookLog は写真をそのまま保存し、位置情報を消しません。** 写真はログインしている人なら誰でも見られるので、自宅などで撮った写真を添えるときは、先に端末の設定や写真アプリで位置情報を消してください。

写真を押すと大きく出ます。2 枚以上あるときは「‹」「›」（キーボードの左右の矢印キー）で切り替えます。「×」、写真の外側、Esc キーで閉じます。

### 5.3 カードの見方

```
┌──────────────────────────────────────────────┐
│ (た) たろう  @taro_y · 3 分前              … │
│      ┌────┐ 本の題名                         │
│      │表紙│ 著者名                           │
│      └────┘ ★★★★☆ 4                        │
│      最後まで一気に読んだ。主人公の決断の…    │
│      続きを読む                               │
│      ┌──────────┐ ┌──────────┐               │
│      │ 写真 1   │ │ 写真 2   │               │
│      └──────────┘ └──────────┘               │
│      [👍 参考になった 12]   💬 3             │
└──────────────────────────────────────────────┘
```

| 部分 | 意味・できること |
| --- | --- |
| 表示名・@ユーザー ID | 押すと、その人のプロフィール |
| 3 分前 | 投稿した日時。1 分未満は「たった今」、24 時間以上たつと「10月16日」のように出ます |
| （編集済み） | 投稿した後に直したレビューに出ます |
| … | 自分のレビューにだけ出ます。押すと「編集」「削除」（5.4） |
| 表紙・書名 | 押すと本のページ（本のページの一覧では出ません） |
| 感想 | 押すとレビューの詳細画面。一覧では 5 行まで出ます。長いときは「続きを読む」で詳細画面に移ります |
| 写真 | 押すと大きく出ます（5.2） |
| 👍 参考になった 12 | 6 章 |
| 💬 3 | コメントの数。押すとレビューの詳細画面 |

### 5.4 直す・削除する

- **直す**：自分のレビューの「…」から「編集」を押します。星・感想・ネタバレあり・写真を変えて「保存する」を押します。何も変えていないと押せません。「キャンセル」で変えずに戻ります
- **削除する**：自分のレビューの「…」から「削除」を押し、確認の画面で「削除」を押します。**写真・コメント・参考になったも一緒に消え、元に戻せません**

直したレビューの一覧での順番は変わりません。

### 5.5 ネタバレありのレビュー

「ネタバレあり」の印が付いたレビューは、感想と写真の代わりに「⚠ ネタバレあり」の枠が出ます（自分のレビューでも同じです）。レビューの詳細画面では、コメントも伏せます。

- 「ネタバレを表示」を押すと出ます
- 別の画面に移ったり読み込み直したりすると、また伏せます
- 星・書名・書いた人は伏せません

## 6. 参考になった

- ほかの人のレビューの「👍 参考になった」を押すと色が付き、数が 1 増えます。もう一度押すと取り消します
- 1 つのレビューに付けられるのは 1 回だけです。何度押しても、最後に押した状態になります
- 自分のレビューには付けられません。数だけが出ます
- ほかの人が押した分は、画面を開き直すと数に入ります

## 7. コメント

レビューの感想か 💬 を押すと、レビューの詳細画面が開きます。

- **書く**：「コメントを書く」に書いて「コメントする」を押します（Ctrl＋Enter／⌘＋Enter でも送れます）。500 文字まで。写真は添えられません
- **読む**：古い順に 50 件ずつ出ます。下の「もっと見る」で続きが出ます
- **消す**：自分のコメントの「削除」を押し、確認の画面で「削除」を押します。コメントは直せません。レビューを書いた人でも、ほかの人のコメントは消せません

## 8. タイムライン

ログインすると開く画面です。

| タブ | 出るレビュー |
| --- | --- |
| フォロー中 | 自分と、フォローしている人のレビュー |
| すべて | 全員のレビュー |

- どちらも新しい順に 20 件ずつ出ます。一番下までスクロールすると続きが出ます
- ほかの人の新しいレビューは自動では出ません。タブを押し直すか、読み込み直すと、最新のレビューから出し直します
- 最後に選んだタブを覚えていて、次に開いたときもそのタブが出ます
- まだ誰もフォローしていないときは「フォロー中」に案内が出ます。「すべて」タブで、気になる人を探してください

## 9. フォロー

- ほかの人のプロフィールの「フォローする」を押すと「フォロー中」になり、その人のレビューがタイムラインの「フォロー中」タブに出ます
- 「フォロー中」を押すとフォローを外します（確認は出ません）。パソコンでは、マウスを乗せると「フォロー解除」と出ます
- フォローに相手の承認は要りません。自分はフォローできません

## 10. プロフィールと本棚

### 10.1 プロフィールを見る

表示名を押すと、その人のプロフィールが開きます。

```
┌──────────────────────────────────────────┐
│ (た)  たろう                 [フォローする] │
│       @taro_y                             │
│       ミステリーをよく読みます              │
│       30 レビュー  12 フォロー  8 フォロワー │
├──────────────────────────────────────────┤
│  レビュー   本棚                           │
└──────────────────────────────────────────┘
```

- 「レビュー」タブには、その人のレビューが新しい順に出ます
- 「フォロー」「フォロワー」を押すと、フォローしている人・フォローされている人の一覧が出ます。上のタブで切り替えられます
- 自分のプロフィールには、フォローボタンの代わりに「プロフィールを編集」が出ます

### 10.2 本棚を見る

「本棚」タブには「読書中」「読了」「読みたい」の小さなタブが、冊数つきで出ます。

- ステータスを付けた（変えた）日時の新しい順に 20 冊ずつ出ます。一番下までスクロールすると続きが出ます
- 本を押すと本のページが開きます
- 本棚は誰でも見られます。変えられるのは自分の本棚だけです（4.1）

### 10.3 プロフィールを変える

1. 自分のプロフィールで「プロフィールを編集」を押す
2. 変えて「保存する」を押す（「キャンセル」で変えずに戻ります）

| 項目 | 決まり |
| --- | --- |
| 表示名 | 1〜30 文字 |
| 自己紹介 | 160 文字まで。改行もできます。空にもできます |

- 変えた表示名は、過去のレビューやコメントにも出ます
- ユーザー ID とパスワードは変えられません。アイコンの画像はありません（表示名の 1 文字目を丸の中に出します）

## 11. メッセージが出たとき

| メッセージ | 原因と、すること |
| --- | --- |
| このユーザー ID は使われています。 | ほかの人が使っています。別の ID にしてください |
| ユーザー ID は 3〜15 文字の半角英数字と「_」で入力してください。 | 決まりに合わせて直してください（2.1） |
| パスワードは英字と数字を含む 8〜64 文字の半角文字で入力してください。 | 同上 |
| パスワード（確認）が一致しません。 | 2 つのパスワードを同じにしてください |
| 表示名を入力してください。 | 表示名を 1 文字以上入れてください |
| ユーザー ID かパスワードが違います。 | 入れ直してください。5 回続けて間違えると 15 分間ログインできなくなります |
| ログインに続けて失敗したため、15 分間ログインできません。 | 15 分たってからログインしてください |
| ログインの有効期限が切れました。もう一度ログインしてください。 | 14 日間使わなかったか、安全のためにログインを切りました。ログインし直してください |
| パスワードが違います。 | 退会の画面で、パスワードが違います。入れ直してください。何回間違えてもログインできなくなることはありません |
| ISBN か書名を入力してください。 | 検索欄に文字を入れてください |
| 「（入れた文字）」に一致する本は見つかりませんでした。 | 別の書き方で探してください。見つからない本は登録できません（3.3） |
| 本の検索がいまできません。時間をおいてもう一度お試しください。 | 時間をおいて探し直してください（3.3） |
| この本は見つかりません。 | URL が違うか、選んだ本が Google Books からなくなっています |
| 星を 1〜5 から選んでください。 | 星を選んでください |
| 感想を入力してください。 | 感想を 1 文字以上入れてください |
| この本のレビューはすでに書いています。 | 別のブラウザなどで先に書いています。今のレビューを直す画面が開きます |
| このレビューは削除されました。 | 書いた人が削除したか、退会しました |
| 投稿に失敗しました。時間をおいてもう一度お試しください。 | 入れた内容と写真は残っています。少し待ってから、もう一度押してください |
| 写真は 1 つのレビューに 4 枚までです。 | 先に選んだものから 4 枚までを添えました |
| 添えられるのは 5MB までの JPEG・PNG・WebP の画像です。 | 別の写真を選んでください |
| 写真を読み込めませんでした | 画面を読み直してください |
| この本棚にはまだ本がありません。 | その分類の本はまだありません |
| このユーザーは見つかりません。 | ユーザー ID が違うか、その人は退会しました |
| 読み込みに失敗しました。時間をおいてもう一度お試しください。 | 「再読み込み」を押してください |
| 操作に失敗しました。時間をおいてもう一度お試しください。 | 参考になった・フォロー・読書ステータス・コメント・削除・保存が届きませんでした。少し待ってからやり直してください |
| インターネットに接続されていません。接続を確認してください。 | 機器のインターネットの接続を確かめてください。つながると消えます |
| BookLog は止めています | サーバーを止めている時間です。動かしている時間に開き直してください |

## 12. できないこと

- Google Books にない本の登録、本の情報の修正
- パスワードの再発行、ユーザー ID の変更、アイコン画像の設定
- コメントの編集
- 読んだページ数・読み終えた日の記録
- レビュー・ユーザーの検索、おすすめの表示
- 鍵アカウント、ブロック・ミュート・通報
- 通知、ダイレクトメッセージ
- 退会した後のデータの復元
- 日本語以外の表示

不適切なレビューや写真を見つけたときは、運営者に知らせてください。
