## 1. 本書について

### 1.1 目的

要件定義書 8 章の機能一覧にある機能ごとに、「利用者が何をできるか（機能要件）」と「そのためにアプリが何をするか（処理・入力の確認・API・データ・エラー）」を 1 つの文書にまとめる。1 つの機能を作るときに、その機能の文書を読めば作れるようにする。

機能ごとの文書は、すべて次の章立てにする。その機能に当てはまらない章は「なし」と書く。

| 章 | 内容 |

| 1. 概要 | 目的、使う画面、関係する機能、前提 |

| 3. 処理の流れ | 画面・API・データベース・S3・Google Books API の間で何が起きるか（Mermaid の図） |

| 8. 権限 | 誰が何をできるか |
| 9. エラーとメッセージ | 起きうるエラーと、画面に出すメッセージ・HTTP ステータス |

## 2. 共通の決まり（画面）

- 用語（トリム、文字数、ネタバレありなど）は要件定義書 5 章のとおり
- 「誰でも見られる」は、ログインしているユーザーなら誰でも、という意味である。ログインしていない人は何も見られない（N-12）
- 参考になった・フォロー・読書ステータス・コメント・削除・保存に失敗したときは、画面をその操作の前の状態に戻して M-30 を出す
- インターネットに接続できないことに気づいたら M-31 を出し、接続が戻ったら消す
- API が 401 を返した（JWT の期限が切れた）ときは、画面は利用者に知らせずに POST /api/auth/refresh で JWT を取り直し、元の操作を 1 回だけやり直す。取り直しにも失敗した（ログインの期限が切れていた）ときは、M-8 を出して G-1 に移す（FN-01 A-8）
- ネタバレありのレビューは、どの画面でも感想・写真・コメントを伏せて出す。開いた状態は、その画面を開いている間だけ覚える（FN-03 RV-11）
- 星は「★★★★☆ 4」のように、星の形と数字を並べて出す（N-24）

## 3. 共通の決まり（API）

### 3.1 基本

| 項目 | 決まり |
| --- | --- |
| URL | すべて /api で始める。画面の URL（/books/1 など）と分ける |
| 形式 | 入力・出力とも JSON（UTF-8）。写真を送るときだけ multipart/form-data |
| ID | 数値（bigint）。JavaScript で扱える範囲（2 の 53 乗未満）に収まる |
| ユーザーの指定 | URL ではユーザー ID（username）で指定する。大文字・小文字は区別しない |
| 日時 | ISO 8601 形式の UTC（例：2026-11-01T06:30:00Z）。画面で日本時間に直す |
| 文字列 | サーバー側でもトリムし、改行を LF にそろえてから文字数をコードポイントで数えて確かめる（画面の確認だけに頼らない） |
| Google Books API | 画面からは呼ばない。必ず本アプリの API を通す（API キーを画面に渡さないため。N-18） |

### 3.2 ログイン（JWT 認証）と CSRF 対策

ログインの状態はサーバーに覚えさせず（セッションを使わない）、JWT で確かめる（N-19）。流れは FN-01 の 3 章のとおり。

| 項目 | 決まり |
| --- | --- |
| アクセストークン | JWT。署名は HS256（秘密の値は Parameter Store。N-18）。中身は sub（ユーザーの ID）・username・iat（発行時刻）・exp（期限）。有効期限 15 分 |
| リフレッシュトークン | 推測できない 32 バイトの乱数を文字列にしたもの（JWT ではない）。有効期限 14 日。データベースには SHA-256 のハッシュだけを保存する |
| 渡し方 | どちらも Cookie（HttpOnly・SameSite=Lax、公開時は Secure）で渡す。アクセストークンは `access_token`（Path=/api）、リフレッシュトークンは `refresh_token`（Path=/api/auth）。画面の JavaScript からは読めない |
| 確かめ方 | Spring Security の OAuth2 Resource Server の JWT の確認を使い、Cookie の access_token を読む。署名・期限が正しければ、データベースを読まずに sub の人としてログイン済みにする |
| ログインしたままにする | アクセストークンの期限が切れたら、POST /api/auth/refresh で両方を新しくする。リフレッシュトークンは使うたびに新しいものに替える |
| ログアウト | リフレッシュトークンをデータベースで無効にし、両方の Cookie を消す |
| 退会した人の JWT | 退会した人の JWT が期限内に使われたときは、その人がデータベースにいないため 401 UNAUTHENTICATED を返す（データを読み書きする API は、必ずログインした人がいるかを確かめる） |
| CSRF | Cookie（XSRF-TOKEN）に入れたトークンを、画面が X-XSRF-TOKEN ヘッダーで送り返す。GET 以外のすべての API で確かめる。トークンを新しくするのはログイン・登録のときだけ |
| ログインがいらない API | POST /api/auth/signup、POST /api/auth/login、POST /api/auth/refresh、GET /api/auth/username-availability だけ。それ以外はアクセストークンがなければ 401 |

### 3.3 エラーの形

エラーのときは、HTTP ステータスと次の JSON を返す。画面は message をそのまま出し、field があればその入力欄の下に出す。

```json
{
  "code": "USERNAME_TAKEN",
  "message": "このユーザー ID は使われています。",
  "field": "username"
}
```

| HTTP ステータス | 使うとき |
| --- | --- |
| 400 | 入力が条件に合わない（code は各機能定義書の 9 章）。画面を通さずに送られた入力（JSON が読めない、画面では入力できない長さなど）は、code を BAD_REQUEST、message を「入力が正しくありません。」にする |
| 401 | ログインしていない（UNAUTHENTICATED）、アクセストークンの期限切れ（TOKEN_EXPIRED）、リフレッシュトークンが使えない（REFRESH_FAILED） |
| 403 | 権限がない（他人のレビューの削除、自分のレビューへの参考になったなど）、CSRF トークンが合わない |
| 404 | 本・レビュー・ユーザーなどが存在しない |
| 409 | 重複（使われているユーザー ID、同じ本への 2 つ目のレビュー） |
| 413 | 写真が大きすぎる |
| 423 | ログインの失敗が続いて、ログインできない（FN-01 A-7） |
| 500 | サーバーの中の失敗（S3・データベースの障害など）。message は M-21 か M-30 |
| 503 | Google Books API が使えない、または 1 日の回数の上限に達した（BOOK_SEARCH_UNAVAILABLE。FN-02） |

### 3.4 一覧の読み込み（ページング）

| 項目 | 決まり |
| --- | --- |
| 方法 | カーソル方式。前回の出力の nextCursor を、次の入力の cursor にそのまま渡す。最後まで読んだら nextCursor は null |
| 件数 | タイムライン・レビュー・フォロー・本棚の一覧は 20 件、コメントは 50 件 |
| カーソルの中身 | 新しい順の一覧は「最後に出した行の ID」、日時順の一覧は「最後に出した行の日時と ID」を文字列にしたもの。画面はカーソルの中身を読まない |
| 例外 | 書籍検索だけは Google Books API の決まりに合わせ、件数（page。1 から）で指定する（FN-02） |

一覧を返す API の出力は、すべて次の形にする。

```json
{
  "items": [ … ],
  "nextCursor": "1234"
}
```

### 3.5 よく使う出力の形

#### レビュー（ReviewView）

```json
{
  "id": 1234,
  "author": { "username": "taro_y", "displayName": "たろう" },
  "book": { "id": 56, "title": "本の題名", "authors": ["著者名"], "thumbnailUrl": "https://books.google.com/…" },
  "rating": 4,
  "body": "最後まで一気に読んだ。…",
  "spoiler": false,
  "photos": [
    { "id": 77, "url": "https://…（署名付き URL）", "expiresAt": "2026-11-01T06:45:00Z" }
  ],
  "helpfulCount": 12,
  "commentCount": 3,
  "helpfulByMe": true,
  "mine": false,
  "createdAt": "2026-11-01T06:30:00Z",
  "editedAt": null
}
```

- spoiler が true でも body と photos は返す。伏せるのは画面の表示だけである（ログインした人なら誰でも見てよい内容のため）
- editedAt は最後に編集した日時。編集していなければ null
- 一覧では body を全部返し、途中で切るのは画面で行う

#### 本（BookSummary）

```json
{
  "id": 56,
  "title": "本の題名",
  "authors": ["著者名"],
  "thumbnailUrl": "https://books.google.com/…"
}
```

thumbnailUrl は、表紙がない本では null。

#### ユーザー（UserSummary）

```json
{
  "username": "taro_y",
  "displayName": "たろう",
  "bioFirstLine": "ミステリーをよく読みます",
  "followedByMe": false,
  "me": false
}
```
