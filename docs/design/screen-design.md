## 1. 本書について

画面一覧（G-1〜G-13）と画面遷移は[画面一覧](../requirements/screens.md)のとおりで、本書には書かない。本書では、全画面に共通の決まり（2 章）と、画面ごとのレイアウト・表示項目・操作（3 章〜15 章）を決める。表の「操作」の列の ID は、その操作を定めている機能要件である。

## 2. 共通仕様

### 2.1 色

| 名前 | 用途 | 色 |
| --- | --- | --- |
| 画面背景 | すべての画面の背景 | #FFFFFF |
| 区切り線 | カードの間、ヘッダーの下、入力欄の枠 | #E5E7EB |
| 文字 | 通常の文字 | #101828 |
| 補足文字 | @ユーザー ID・日時・件数・著者・残りの文字数 | #475467 |
| 主色 | 主ボタンの背景、選んでいるタブの下線、リンク、押した「参考になった」の文字と枠 | #1A5FB4 |
| 主色の薄い背景 | 押した「参考になった」・選んでいる読書ステータスのボタンの背景 | #E8EEF7 |
| 星の色 | 塗った星 | #B54708 |
| 星の空き | 塗っていない星 | #98A2B3 |
| 危険色 | 削除・退会のボタンの背景、エラーの文字、上限を超えた残りの文字数 | #B42318 |
| 枠の背景 | 「表紙なし」の枠、「ネタバレあり」の枠、頭文字の丸 | #F2F4F7 |
| お知らせ（警告） | 通信切れ（M-31）の背景 | #FFEBE6 |
| 背景の覆い | ダイアログを開いたときに後ろの画面を覆う色 | 黒・透明度 50%（G-11 は 85%） |

文字と背景の組み合わせは、実装のときにコントラストを確かめる道具（E2E の axe-core）で 4.5:1 以上（N-21）であることを確かめる。星の空き（#98A2B3）は飾りで、星の数は必ず数字でも出す（2.8）。

### 2.2 文字

| 対象 | 大きさ | 太さ |
| --- | --- | --- |
| アプリ名（ヘッダー） | 20px | 太字 |
| 画面の見出し・ダイアログの見出し・G-5 の書名 | 18px | 太字 |
| 表示名・カードの書名 | 15px | 太字 |
| 感想・コメント・紹介文 | 15px | 標準 |
| その他すべて | 14px | 標準 |

書体は、Windows では「メイリオ」または「Yu Gothic UI」、macOS・iOS では「ヒラギノ角ゴシック」、Android では「Noto Sans JP」を使う（OS に入っているものを使い、書体ファイルは配布しない）。

### 2.3 ボタン

| 種類 | 見た目 | 使う場所 |
| --- | --- | --- |
| 主ボタン | 主色の背景・白い文字 | ログイン、登録する、投稿する、保存する、コメントする、フォローする、レビューを書く |
| 通常ボタン | 枠線のみ・文字色 | キャンセル、写真を選ぶ、フォロー中、もっと見る、再読み込み、ネタバレを表示、レビューを編集 |
| 切り替えボタン | 押していないときは通常ボタン。押しているときは主色の薄い背景・主色の枠と文字 | 参考になった、読書ステータス（読みたい・読書中・読了） |
| 危険ボタン | 危険色の背景・白い文字 | 削除、退会する |

- 高さ 36px、角の丸み 18px（両端が丸い形）、左右の余白 16px
- マウスを乗せるとカーソルを指の形にし、背景を 10% 暗くする
- 押せない状態のときは、透明度 50% で出し、カーソルを禁止マークにする
- 切り替えボタンには、押しているかどうかを読み上げられるよう aria-pressed を付ける
- 「フォロー中」ボタンは、マウスを乗せている間だけ文字を「フォロー解除」、枠線と文字を危険色にする（F-2）

### 2.4 メッセージの表示方法

| 方法 | 位置 | 消えるとき | 使うメッセージ |
| --- | --- | --- | --- |
| 入力欄の下 | 入力欄のすぐ下に危険色の文字 | その入力欄に入力したとき | M-1〜M-5、M-10、M-16、M-17 |
| フォームの上 | G-1 の「ログイン」ボタンの上 | 次に「ログイン」を押したとき | M-6〜M-8 |
| 一覧の代わり | 一覧・画面の中身を出す場所の中央に補足文字で出す | 出すものができたとき | M-13〜M-15、M-20、M-25〜M-28 |
| 一覧の下 | 読み込みに失敗した場所に「再読み込み」ボタンと一緒に出す | 「再読み込み」で成功したとき | M-29 |
| トースト | 画面の下中央、幅 360px（画面が狭いときは左右 16px を空けた幅）。右端に「×」 | 「×」を押したとき、または 5 秒たったとき。同時に出すのは 1 つで、新しいものが出たら古いものは消す | M-11、M-12、M-18、M-21〜M-23、M-30 |
| お知らせ欄 | ヘッダーのすぐ下、画面の横幅いっぱい | 接続が戻ったとき | M-31 |
| ダイアログ | G-12・G-13 | ボタンを押したとき | M-9、M-19、M-24 |

### 2.5 ダイアログ共通

- 画面の中央に出し、後ろの画面を「背景の覆い」で覆う。開いている間は後ろの画面を操作できない
- Esc キー、または覆いの部分のクリックで、「キャンセル」「閉じる」と同じ動きをする
- G-12・G-13 を開いたときは「キャンセル」ボタンにカーソルを置く（Enter キーで誤って削除・退会しないため）
- 閉じたら、開く前に押したボタンにカーソルを戻す

### 2.8 星

#### 表示

「★★★★☆ 4」のように、星 5 つと数字を並べる。星は 16px（G-5 の平均評価は 24px）。塗った星は星の色、塗っていない星は星の空きの色。読み上げでは星の形を読ませず、「星 4（5 段階中）」と読ませる（aria-label。N-24）。

平均評価（G-5）は、平均を四捨五入した整数の数だけ星を塗り、数字は小数点以下 1 桁で出す（「★★★★☆ 4.2」。FN-10 の 5 章の 1）。

#### 入力（G-6）

```
星（必須）  ☆ ☆ ☆ ☆ ☆   選んでいません
星（必須）  ★ ★ ★ ★ ☆   4（5 段階中）
```

| 項目 | 内容 | 操作 |
| --- | --- | --- |
| 星のボタン | 星 5 つ。1 つ 32px 四方で、押せる大きさを 44px 四方にする。1 つのグループ（radiogroup）として、それぞれを「星 1」〜「星 5」と読ませる | 押した星まで塗る。左右の矢印キーで 1 つずつ変えられる（RV-3） |
| 選んだ数 | 星の右に補足文字で「4（5 段階中）」。選んでいないときは「選んでいません」 | |

### 2.9 表紙

| 状態 | 表示 |
| --- | --- |
| 表紙の URL がある | 縦横の比を保って枠に収める（CSS の object-fit: contain）。代わりの文字（alt）は「（書名）の表紙」 |
| 表紙の URL がない、画像を読めない | 枠の背景の色の枠に、補足文字で「表紙なし」（B-7） |

| 使う場所 | 幅 × 高さ |
| --- | --- |
| レビューのカード・G-6 の本 | 48px × 72px |
| G-4 の検索の結果 | 64px × 96px |
| G-8 の本棚 | 列の幅いっぱい × 幅の 1.5 倍 |
| G-5 | 128px × 192px |

表紙の画像は Google Books のものを、その URL のまま読む（要件定義書 P-3）。

### 2.10 頭文字の丸

ヘッダー・レビューのカード・コメント・ユーザーの行・G-8 で、ユーザーを表す丸である。枠の背景の色の丸に、表示名の 1 文字目を出す。アイコン画像はない（要件定義書 2.2）。

| 使う場所 | 直径 |
| --- | --- |
| ヘッダー・コメント | 32px |
| レビューのカード・ユーザーの行 | 40px |
| G-8 | 80px |

### 2.11 ユーザーの行（G-10 で使う）

```
│ (た) たろう  @taro_y                   [フォロー中]   │
│      ミステリーをよく読みます                          │
```

| 項目 | 内容 | 操作 |
| --- | --- | --- |
| 頭文字の丸・表示名・@ユーザー ID | 2.10、2.7 と同じ | 行を押すとその人の G-8（F-6） |
| 自己紹介の 1 行目 | 補足文字。60 文字を超えたら「…」で省く（FN-11 の 5 章の 4） | |
| フォローボタン | 自分以外の行の右に出す | F-1・F-2 |

### 2.12 入力の共通ルール

- 前後の空白（半角スペース・全角スペース・タブ・改行）を取り除いてから、文字数の確認と保存を行う
- 文字数は要件定義書の用語「文字数」のとおり、Unicode の文字（コードポイント）単位で数える
- 感想は、2,000 文字を超えても入力はできる（あとで削れるように）。超えている間は送信できない（RV-4）。それ以外の入力欄は、上限を超える文字を入力できないようにする
- 1 行の入力欄で Enter キーを押すと、その画面の主ボタンと同じ動きをする。日本語入力の変換を確定するための Enter キーでは送信しない
- 感想・コメント・自己紹介の入力欄では、Enter キーで改行し、Ctrl＋Enter（macOS では ⌘＋Enter）で送信する

### 2.13 日付・日時の表示

| 経過した時間 | 表示 |
| --- | --- |
| 1 分未満 | 「たった今」 |
| 1 時間未満 | 「3 分前」 |
| 24 時間未満 | 「5 時間前」 |
| 同じ年 | 「11月1日」 |
| 前の年以前 | 「2025年11月1日」 |

日時の上にマウスを乗せると、「2026/11/01 15:30」（日本時間、24 時間表記）を出す。本の出版日は、API が返したまま「2024」「2024年5月」「2024年5月10日」の形で出す。

### 2.14 画面の幅

- 中身は横幅 600px の 1 列にして、画面の中央に置く
- 画面の横幅が 600px 未満のときは、横幅いっぱいに広げる（左右の余白 16px）。375px でも横にスクロールしない（N-23）
